- Performed exploratory analysis, cross-tabulation, and risk analysis.

- Documented limitations, sample sizes, and confidence intervals.

### 2. DNA Sequence Analyzer — Version 1
- Developed a Python program to analyze DNA sequences.
- Calculates sequence length, nucleotide counts, and GC content.
- Includes input validation and structured reporting.

### 3. DNA to RNA Converter
- Developed a Python program to convert DNA sequences into RNA sequences.
- Applied string manipulation, functions, and basic sequence-processing concepts.
